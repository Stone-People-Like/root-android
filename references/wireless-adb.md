# 无线 adb 连接

无线 adb 适合查看信息、执行 shell、安装文件；**不能用于 fastboot 刷写**，刷 boot/recovery 仍必须 USB。

## 连接步骤（Android 11+）

1. 开发者选项 → 打开「无线调试」。
2. 电脑与手机连接同一 Wi-Fi。
3. 手机点「无线调试」→「使用配对码配对设备」，记录 IP:端口 和 6 位配对码。
4. 电脑配对：

```bash
adb pair <手机IP>:<配对端口>
# 提示时输入 6 位配对码
```

5. 连接：

```bash
adb connect <手机IP>:<连接端口>
adb devices
```

## 注意事项

- 配对端口和连接端口通常不同，注意区分。
- 重新配对后端口可能变化；IP 变化需重新 connect。
- 防火墙/路由器隔离（AP 隔离）会阻止连接。
- 无线 adb 会话可能因休眠断开；唤醒手机或重新 connect。
- 使用完毕后建议关闭无线调试，降低暴露面。

## 安全验证

- [ ] 确认手机与电脑在同一网络。
- [ ] 配对码来自用户手机屏幕，不来自第三方。
- [ ] 只用于只读/shell/传输操作；刷写一律切回 USB。
